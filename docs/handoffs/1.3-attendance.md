# Handoff: 1.3 Attendance function

## Task
`attendance-recordAttendance` (UC #1-4, #3-4; architecture.md 4.2, 4.3; functions.md section 5): QR or manual ticket-code check-in by the workshop's instructor or an assigned volunteer, once-only, 1 point to the instructor.

## Agent / model
Opus, 2026-10-19.

## What was built
- `controller/decideAttendance.ts` (pure): `decideAttendance(snaps, req, now)` with the 4.3 check order NOT_FOUND -> NOT_AUTHORISED_FOR_WORKSHOP -> SESSION_NOT_ACTIVE -> NO_BOOKING (missing or CANCELLED) -> WRONG_WORKSHOP -> ALREADY_ATTENDED (details `{ learnerName, attendedAt }`); helpers `decideScannerRole`, `isSessionActive`, `methodOf`.
- `repo/attendanceRepo.ts`: `findBookingIdByTicket` (normalise, format check, query `workshopId == W && ticketCode == C`, exactly one match else TICKET_NOT_FOUND) and `recordAttendanceTx` via `runTx`: reads workshop, booking, attendance, volunteer assignment (only when caller is not the instructor), instructor wallet; writes `tx.create(attendance/{bookingId})`, booking `status ATTENDED, attendedAt = now`, workshop `attendedCount` increment, `writeLedgerTx` (`earn_{bookingId}`, `EARN_ATTENDANCE`, amount `POINTS_PER_ATTENDANCE`), `writeAuditTx` (`ATTENDANCE_RECORD`, target WORKSHOP, details bookingId/method/pointsAwarded/instructorId). All in one transaction.
- `handlers/recordAttendance.ts`: `verifyQr` (INVALID_QR) or ticket lookup before the tx; `defineCallable` with roles `ATTENDANCE_STAFF_ROLES`. Exported `recordAttendance(ctx, { ignoreCheckInWindow? })` (default: env `DEMO_IGNORE_CHECKIN_WINDOW`).
- `index.ts` exports `recordAttendance` -> deployed `attendance-recordAttendance`.

## Interfaces exposed
- `attendance-recordAttendance` per functions.md. Output `attendedAt` = server `now` (ISO).
- Stored `attendance/{bookingId}`: Attendance entity with `createdAt = Timestamp(now)`; booking `attendedAt` same instant.
- Audit action `ATTENDANCE_RECORD` (SUCCESS only, written in the tx). Denied scans are not audited.

## Open issues
- `architecture.md` 4.3 / functions.md do not mention the audit entry or the `ATTENDANCE_RECORD` action; docs owner may want to add it.
- Staff check also requires the role: the owner must hold SENIOR_INSTRUCTOR, an assigned scanner must hold VOLUNTEER (stricter than the doc wording, harmless).
- Ticket-code lookup runs before the staff check (spec order), so a non-assigned staff member can distinguish TICKET_NOT_FOUND from NOT_AUTHORISED_FOR_WORKSHOP for a workshop id. Acceptable for the prototype.
- Workshop `version` is not bumped (attendance is not an admin edit), so admin edits during a session don't hit STALE_VERSION.
- Emulator Jest prints "did not exit one second after the test run" (open firebase-admin handles; pre-existing pattern, exit code 0).
