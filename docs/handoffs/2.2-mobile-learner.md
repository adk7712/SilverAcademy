# Handoff: 2.2 Mobile Learner (Discover, Workshop detail, My Bookings, Ticket)

## Task
Replace the placeholders for `DiscoverScreen`, `WorkshopDetailScreen` (workshops) and `MyBookingsScreen`, `TicketScreen` (bookings): UC #2-1, #2-2, #2-3, ADR-018 (client-side search), ADR-019 (offline ticket).

## Agent / model
Sonnet, 2026-10-19.

## What was built
- **Discover**: direct read `workshops where status == 'OPEN' order by startAt limit 200`; keyword search, category select, From/To date (YYYY-MM-DD text, Singapore time, validated), sort Soonest / Nearest, Reset filters, "Recommended for you" (only when unfiltered), "No workshops found" empty state. All filtering uses shared `filterWorkshops`, `sortByStart`, `sortByDistance`, `recommendWorkshops`. Started workshops are hidden client-side.
- **Location**: chosen only when the user picks "Nearest to me" (`expo-location`, via `services/deviceLocation.ts`). Denied/failed: sort stays by date and an explanatory note shows.
- **Workshop detail**: title, category, date/time, venue, instructor, seats (`x of y booked, n left`), description, materials, Book button with an inline confirmation step. Pre-checks (not open / started / full) show a clear banner instead of the button. Server errors WORKSHOP_FULL / WORKSHOP_NOT_OPEN / WORKSHOP_STARTED / ALREADY_BOOKED / CANNOT_BOOK_OWN_WORKSHOP show their messages (workshop reloads on the first three); ALREADY_BOOKED offers "View my ticket" using `details.bookingId`. Success shows a confirmation card with the ticket code and a link to the ticket (`navigate('MyBookingsTab', {screen:'Ticket'})`).
- **My Bookings**: `bookings where learnerId == uid order by createdAt desc`; "Upcoming" and "Past and cancelled" groups with status badges.
- **Ticket**: pure black-on-white QR (react-native-qrcode-svg, up to 360dp) from `qrPayload`, ticket code as `XXXX-XXXX` in display size (manual fallback), attendance status/time, cancelled note, venue/time/instructor.
- **Offline (ADR-019)**: every successful bookings read is mirrored to AsyncStorage `tickets:v1:<uid>` (`learnerBookingModel.ts`). On failure (or an 8 s stalled read, since the RN Firestore SDK never reports offline for reads) the cache is shown with a "last updated" banner on both My Bookings and Ticket.
- Strings in new `i18n/en/workshopsLearner.ts` and `bookingsLearner.ts` (wired into `en/index.ts` with two lines each).
