# Handoff: 4.2 Mobile sweep fixes

## Task
Fix verified findings from a code sweep of `apps/mobile/src`. Owned files only; no commits.

## Fixed
1. Hardcoded `gap` literals in 8 screens/components (11 sites) now use `useTheme().spacing`. Added token `spacing.smd = 12` (no existing token for 12).
2. `pickAttachment` rejection: new `pickFromDevice(picker)` in `useReportIssue` catches it and sets `attachmentError` (`reports.attachPickFailed`); screen uses it.
3. `SessionProvider.setMode`: side effects moved out of the `setState` updater (reads `stateRef`, single call each).
4. `useReportIssue`: if `submitReport` fails after upload, the object is deleted best-effort (`deleteStoragePath` in `services/storageClient.ts`, `deleteAttachment` in `reportRepo`).
5. Removed `services/location.ts`; `useVolunteerOpportunities` uses `getDeviceLocation` (`ok` -> origin, anything else -> denied/unordered). No pure logic existed to test.
6. Removed unused `removeStored`.
7. Separators moved to `i18n/en/common.ts` (`timeRangeTo`, `timeRangeDash`, `dateTimeComma`, `labelDot`); used by `formatWhen`, `dateFormat`, `PointsHistory`. New test `services/dateFormat.test.ts`.
8. `useVenueRequest.load` and `useWallet` set `loading=false` when uid is null.
9. `CameraScanner` effect deps fixed (`needsPrompt`, `requestPermission`). `eslint-plugin-react-hooks` is not installed; not added.
10. `Button` gets optional `expanded` -> `accessibilityState.expanded`; `PointsHistory` passes it.
11. `ThemeProvider`: late-loading stored scale no longer overwrites a scale chosen this session (`hydratedFontScale` in `fontScale.ts`, tested).

## Skipped
