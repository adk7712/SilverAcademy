# Handoff: 2.6 Mobile Volunteer, Report an Issue, Profile, Feedback

## Task
Mobile screens for UC #3-1, #3-2, #3-3 (Volunteer), #2-5 (Report an Issue), Profile extras (notifications, Feedback entry) and #2-4 (learner feedback).

## Agent / model
Sonnet, 2026-10-19.

## What was built
- **Volunteer** (`features/workshops/ui/volunteer/*`, `controller/volunteer*`, `use*`, `repo/volunteerRepo.ts`, `volunteerTypes.ts`):
  - `VolunteerOpportunitiesScreen`: OPEN workshops with `needsVolunteers`, places left, not started. With location: nearest first, default "nearby" (<= `NEARBY_RADIUS_KM` 10 km) with "View all" toggle and a "No nearby opportunities" state; location denied: soonest-first list, notice and "Use my location" retry. Badge for workshops already assigned.
  - `VolunteerOpportunityDetailScreen`: Assist (confirm step; "Not now" creates nothing), `ALREADY_OPTED_IN` shows the current status, `VOLUNTEERS_FULL`/others via `errorMessage`, Withdraw (confirm) via `workshops-withdrawVolunteer`; reloads after each action.
  - `AssignedWorkshopsScreen`: ASSIGNED workshops (upcoming first, then past/cancelled), expandable details, class list loaded lazily via `bookings-getRoster` (NOT_ASSIGNED shown as error), Scan shortcut (`navigate('ScanTab')`).
- **Feedback** (`features/workshops/ui/feedback/FeedbackScreen.tsx`, `controller/feedback*`, `use Feedback`, `repo/feedbackRepo.ts`): attended bookings, 7-day window state (open / sent / closed), rating 1-5, comment, preset tags (max 5), `workshops-submitFeedback`; `FEEDBACK_WINDOW_CLOSED`, `ALREADY_SUBMITTED`, `NOT_ATTENDED` refresh the list and show the message.
- **Report** (`features/reports`): category (shared enums), description (10-2000), optional attachment (expo-document-picker, jpg/png/pdf, <= 5 MB, checked client-side with an oversize message before upload), upload to `reportUploads/{uid}/...`, `reports-submitReport`, big reference number, "My reports" list (`incidents where reporterId == uid`) with status, info request and resolution. Upload failure submits nothing.
- **Profile** (`features/users`): `ProfileScreen` keeps `<AccountPanel />` (text size), adds Feedback button (LEARNER role only), Report an issue, notifications list (read + mark read via `users-markNotificationRead`, optimistic).
- **Services**: `services/location.ts` (expo-location, never throws), `services/filePicker.ts`, `services/storageClient.ts` (Storage + emulator).
- **Strings**: new `i18n/en/workshopsVolunteer.ts`, `usersProfile.ts`; `reports.ts` extended; wired in `i18n/en/index.ts`.
- **Tests** (pure): `volunteerLogic.test.ts`, `feedbackLogic.test.ts`, `reportLogic.test.ts`, `notificationsLogic.test.ts`.
